# Contacts Management API (UMT-pythonweb-hw-13)

A feature-rich contacts management RESTful API built with **FastAPI** and **SQLAlchemy** (using asynchronous queries). This application supports full CRUD operations on contacts, user authentication with email verification, avatar uploads, and JWT-based authorization. It includes database migration tracking with **Alembic**, phone number/email validation, and rate limiting.

Now includes **Redis Caching** for authorization, **Password Reset** flow, **User Roles** (User & Admin), **Sphinx Documentation**, and a robust **Pytest suite** with over **84% test coverage**.

## Key Features

- ✅ **User Authentication & Roles** - Register, login with JWT tokens. Role-based access control ("user" and "admin").
- ✅ **Role-based Access Control** - Only administrators can update their avatars (`PATCH /api/users/avatar`).
- ✅ **Redis Caching** - Cached user profiles on authentication in `get_current_user` to reduce DB hits.
- ✅ **Password Reset Flow** - Secure password reset via email verification token.
- ✅ **Email Verification** - Send confirmation emails before account activation.
- ✅ **Avatar Upload** - Upload and manage user avatars via Cloudinary (restricted to Admin users).
- ✅ **Rate Limiting** - Protect endpoints with slowapi rate limiting.
- ✅ **Full CRUD Contacts** - Create, read, update, delete contacts per user.
- ✅ **Birthday Filtering** - Find contacts with upcoming birthdays in the next 7 days.
- ✅ **Sphinx Documentation** - Autogenerated documentation with docstrings.
- ✅ **Pytest Suite** - Over 84% test coverage checking repos, services, and API routes.

## Technologies Used

- **FastAPI**: Modern, asynchronous web framework for building APIs.
- **SQLAlchemy (Async)**: Object-Relational Mapper (ORM) using `asyncio` for non-blocking queries.
- **Alembic**: Database migration tool for SQLAlchemy schemas.
- **PostgreSQL / asyncpg**: Asynchronous relational database storage.
- **Redis**: In-memory database used for high-performance user caching.
- **pytest & pytest-cov**: Test suite runner and coverage tracker.
- **aiosqlite**: Async SQLite support for in-memory test database.
- **Sphinx**: Documentation generator.
- **Passlib & Bcrypt**: Secure password hashing.
- **Python-Jose**: JWT token creation and validation.
- **Cloudinary**: Cloud-based image storage for avatar uploads.
- **SlowAPI**: Rate limiting middleware for FastAPI.
- **uv**: Modern, high-performance Python package and workspace manager.

## API Endpoints

### Authentication Routes (`/api/auth`)

| Endpoint                           | Method | Description                             | Auth Required |
| :--------------------------------- | :----- | :-------------------------------------- | :------------ |
| `/api/auth/register`               | `POST` | Register a new user account             | No            |
| `/api/auth/login`                  | `POST` | Login and get JWT access token          | No            |
| `/api/auth/confirm_email/{token}`  | `GET`  | Confirm email with verification token   | No            |
| `/api/auth/request_email`          | `POST` | Request email verification (resend)     | No            |
| `/api/auth/request-password-reset` | `POST` | Request password reset email link       | No            |
| `/api/auth/reset-password/{token}` | `POST` | Reset password using the token received | No            |

### Users Routes (`/api/users`)

| Endpoint            | Method  | Description                                 | Auth Required |
| :------------------ | :------ | :------------------------------------------ | :------------ |
| `/api/users/me`     | `GET`   | Get current user profile                    | Yes (Cached)  |
| `/api/users/avatar` | `PATCH` | Upload/update user avatar (Admin role only) | Yes (Admin)   |

### Contacts Routes (`/api/contacts`)

| Endpoint                           | Method   | Description                                | Auth Required |
| :--------------------------------- | :------- | :----------------------------------------- | :------------ |
| `/api/contacts/`                   | `GET`    | List all user contacts with pagination     | Yes           |
| `/api/contacts/`                   | `POST`   | Create a new contact                       | Yes           |
| `/api/contacts/{contact_id}`       | `GET`    | Get contact details by ID                  | Yes           |
| `/api/contacts/{contact_id}`       | `PUT`    | Update contact information                 | Yes           |
| `/api/contacts/{contact_id}`       | `DELETE` | Delete a contact                           | Yes           |
| `/api/contacts/upcoming-birthdays` | `GET`    | Get contacts with birthdays in next 7 days | Yes           |

## Setup Instructions

### Prerequisites

- Python 3.14+
- Docker & Docker Compose
- Cloudinary Account
- SMTP server credentials

### 1. Clone and Configure Environment

```bash
git clone <repository-url>
cd UMT-pythonweb-hw-13
cp .env.example .env
```

Edit your `.env` file to configure secrets and servers:

```env
# PostgreSQL Configuration
POSTGRES_DB=contacts_app
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_PORT=5432
POSTGRES_HOST=localhost

DB_URL=postgresql+asyncpg://${POSTGRES_USER}:${POSTGRES_PASSWORD}@${POSTGRES_HOST}:${POSTGRES_PORT}/${POSTGRES_DB}

# JWT
JWT_SECRET=your_jwt_secret_key
JWT_ALGORITHM=HS256
JWT_EXPIRATION_SECONDS=3600

# Redis Caching
REDIS_HOST=localhost
REDIS_PORT=6379

# Cloudinary
CLD_NAME=your_cloudinary_name
CLD_API_KEY=your_api_key
CLD_API_SECRET=your_api_secret

# Email (SMTP)
MAIL_USERNAME=example@meta.ua
MAIL_PASSWORD=secretPassword
MAIL_FROM=example@meta.ua
MAIL_PORT=465
MAIL_SERVER=smtp.meta.ua
```

### 2. Start PostgreSQL & Redis

Use Docker Compose to launch both database and cache instances:

```bash
docker-compose up -d
```

### 3. Run Migrations & Start Server

Ensure all dependencies are synced and DB schema is up-to-date:

```bash
uv sync
uv run alembic upgrade head
uv run python main.py
```

Swagger UI will be interactive at: `http://127.0.0.1:8000/docs`.

## Testing & Coverage

We use `pytest` combined with `pytest-cov` to verify operations. Testing uses an in-memory SQLite database and mocks Redis and email sending to avoid dependency clashes.

### 🧪 How to Run Tests

You can run the tests using the following commands:

**Run all tests:**
```bash
uv run pytest
```

**Run all tests with coverage report (showing missing lines):**
```bash
uv run pytest --cov=src --cov-report=term-missing
```

**Run a specific test file:**
```bash
uv run pytest tests/api/test_auth.py
```

**Run a specific test by name:**
```bash
uv run pytest -k "test_login_user"
```

Currently, the test suite covers **84% of the codebase**, ensuring that all repositories, services, and API routes work correctly.
